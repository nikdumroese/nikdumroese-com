Lab · 4 tools · updated October 2026

Four tools you can run.

They come from my work on marketing agents and CRM data. Each one runs in your browser on sample data, and the CRM tool also takes your own CSV. Change an input and the results update.

Brand & claims gate for AI-written copy Checks AI-written ad copy against brand voice, approved claims, competitor mentions and regulated wording, then passes, holds or blocks each draft. Default run: needs review, 3 warnings add up to 35 against a limit of 20 Open → CRM dedupe & standardiser Turns a messy contact export into one clean record per person and explains every merge. Your file stays in your browser. Default run: 328 rows → 201 records, 7 pairs left for review Open → Multi-agent swarm with no one in charge Replays a real run in which agents agree on work without a coordinator. See why each proposal passed, then add an objection and watch the outcome change. Default view: an objection at event 15 reopens a proposal that had already passed Open → Governance layer for marketing agents Logs and checks every action a marketing agent takes, then records whether it would auto-approve, need review or be blocked. Decide the held ones and the weekly report updates. Default run: 22 of 27 actions auto-approve, 3 need review, 2 are blocked Open →
